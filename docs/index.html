AIエージェントに、手足と目を。

クラウドAIの実行環境には、外から直接つなぐ入り口がありません。Agent Hands Kit は発想を変え、人間用の入り口（デスクトップGUI・チャット・共有フォルダ）をAIが使える手足でそのまま使うための、実運用で鍛えたツール群です。

3つの柱

バラバラの小道具ではなく、「見て・操作し・受け渡す」ための一式です。

Desktop Agent

GUIの手足

Windowsの対話デスクトップを「見て→要素を指定して操作する」常駐エージェント。UI Automation のスナップショット（差分・刈り込みでトークン節約）、スクリーンショット、貼り付け／打鍵の二方式入力。裏側APIの無いアプリまで操作できます。

App Wrappers

制作アプリの実行腕

Blender / Inkscape / GIMP / FreeCAD / KiCad / LTspice をヘッドレスにスクリプト実行するラッパー群。成否は終了コードでなく「宣言した成果物ができたか」で判定します。画像の目視確認を軽くする img-peek 付き。

Tools & Patterns

連携と委任の型

PowerShell道具12本（委任・ジョブ管理・ロック・Web読み・文書抽出ほか）、共有フォルダを指示と成果物の受け渡し場所にする「ファイル郵便ポスト」、長い作業を別AIへ渡す「委任ハーネス」の設計パターン。

構成

リポジトリの components/ 配下に、部品ごとに分かれています。

部品内容
desktop-agent/C# / .NET デスクトップGUIエージェント本体＋詳細README＋素通しクライアント desktop.ps1。localhost＋トークン認証のみ
app-wrappers/制作アプリのバッチ実行ラッパー7本（Blender / Inkscape / GIMP / FreeCAD / KiCad / LTspice / img-peek）
powershell-tools/委任・ジョブ・ロック・Web読み・全文検索・自己スケジュール等の道具12本
voicevox-harness/VOICEVOXをGUIなし（エンジンAPI）で操作する音声合成ハーネス。アクセント/ピッチ計画の表示と、出力WAVのF0実測検証付き
notification-watcher/Windows通知をイベント入口にする補助ツール
patterns/ ・ mailbox/委任ハーネスの設計パターンと、ファイル郵便ポストの設計・テンプレート

実例：デモ動画の制作、全部AIで

オープンソースCAD「SolidCraft」のデモ動画は、撮影からナレーション付けまで、すべてAIエージェントがこのキットの道具で実行しました。

  • 撮影 — デスクトップエージェントが SolidCraft を操作する AI（Claude）の作業を画面録画。蝶番のモデリング、回転ジョイントの確認、図面作成までを収録し、テロップを付けて編集。
  • ナレーション — voicevox-harness（vv-say）が VOICEVOX を GUI なしで操作し、テロップの内容に合わせた解説音声をシーンごとに生成。出力は F0 実測で検証済み。
  • 完成 — 解説音声をシーンの開始位置に合わせて合成し、ナレーション入りの動画として完成。原稿作成も含め、人の手は指示だけです。

使い方

前提は Windows 10/11、.NET 10 SDK、PowerShell 5.1 以降です。

git clone https://github.com/thanatos333/agent-hands-kit.git

# Desktop Agent のビルドと配置（単一ファイル exe）
dotnet publish components/desktop-agent -c Release -o $env:USERPROFILE\tools\desktop-agent

トークンの生成、常駐タスクの登録、道具の配置先などの詳しい手順は、リポジトリ内の README と各部品のドキュメントにあります。任意で Tailscale 等のプライベートネットワーク（クラウドAI⇔PCの接続）、Google Drive 等の共有ストレージ（郵便ポスト）を組み合わせます。

安全設計

強い権限を持つ道具だからこそ、境界を先に決めてあります。詳細はリポジトリの SECURITY.md へ。

  • 外に開かない — Desktop Agent は 127.0.0.1 のみで待ち受け、トークン認証必須。トークンは利用者本人のみ読める場所に置く。
  • 確認は要所だけ — 送信先とフォアグラウンドの確認（前1回）と、実行後の表示確認（1回）に絞る設計。速度と安全の両立を実運用で調整した結果です。
  • 結果はマーカーで判定 — 出力本文ではなく最終行の *_OK / *_FAILED で成否を機械判定し、長い出力はファイルへ逃がす。
  • 自分のPCを、自分のAIに — 他人のPCの操作や、規約に反する自動化のための道具ではありません。

CLI-Anything との違い

「AIエージェントにアプリを使わせる」道具には、香港大学の CLI-Anything という大きな先行プロジェクトがあります。目的は同じでも、攻め方が逆です。

Agent Hands KitCLI-Anything
攻め方人間用の表側（デスクトップGUI）をそのまま操作する。スクリプト実行できるアプリにはラッパーも併用アプリの裏側（スクリプト基盤・内部API）に接続する CLI を自動生成する
操作できる範囲GUI さえあれば何でも。裏側に API の無いアプリや Web サービスも対象スクリプト基盤や API のあるアプリだけ（無いアプリは包めない）
実行環境Windows ネイティブ。PowerShell と単一ファイル exe だけPython ＋生成ハーネス一式。Windows では Git Bash / WSL が必要
自由度スクリプトを丸ごと書けるので、上限はアプリの全機能そのものあらかじめ用意されたコマンドの範囲内
重さ.ps1 1枚＋exe 1個。依存ほぼゼロ、壊れても自分で直せる状態管理・REPL・テスト基盤込みの分、仕組みは大きい
強みGUI しかないアプリを触れること、軽さ、自由度対応アプリの多さ（40+）、テスト済みコマンドの再現性

対応表とテストが揃った定型運用なら CLI-Anything も良い選択です。Windows で、画面しかないアプリまで含めて軽く・自由に使いたいなら Agent Hands Kit をどうぞ。
