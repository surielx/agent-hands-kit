Agent Hands Kit 構成 実例 導入ガイド English GitHub

導入ガイド

Agent Hands Kit を Windows PC に入れて、あなたのAIに「手足と目」を渡すまでの手順です。むずかしい知識はいりません。方法は3つ、行き着く先は同じです。

あなた方法を1つ選ぶだけ
→
A：AIに任せるリンクを貼って一言
B：AIに教わるチャットで一歩ずつ
C：自分で入れる手順どおりに
→
導入完了AIがPCを操作できる

用意するもの

必須は Windows PC とインターネットだけ。アプリ類は「使いたいものだけ」で大丈夫です。

もの備考
Windows 10 / 11 のPC必須。セットアップ時は管理者アカウントでログインしてください
インターネット接続キットと .NET SDK のダウンロードに使います
.NET 10 SDK（無料）Desktop Agent のビルドに必要。方法AならAIが入れてくれます
Blender / Inkscape / GIMP / FreeCAD / KiCad / LTspice任意。AIに使わせたいアプリだけ、普通にインストールしておけばOK（場所は自動で見つけます）
VOICEVOX任意。音声合成ハーネスを使う場合のみ。公式サイトからインストール
Python 3任意。VOICEVOXハーネス用（ライブラリ2つを追加します）

方法A：AIに任せる（いちばん簡単）

PC上でコマンドを実行できるAI（Claude Code、Claude のデスクトップアプリのコーディング機能、OpenAI Codex、ターミナルを使えるローカルLLM等）を持っているなら、これが最短です。PCを用意して、リンクを貼って、一言頼むだけです。

そのままコピーしてAIに貼るだけhttps://github.com/thanatos333/agent-hands-kit/blob/main/SETUP.md の導入ガイドを読んで、このWindows PCに Agent Hands Kit をセットアップしてください。手順はガイドの「Way C」に従うこと。部品ごとに検証まで行い、結果行（成功は _OK で終わる行）を見せてください。Desktop Agent のスクリーンショット確認は省略しないこと。失敗したら、エラーと対処を見せてから続けてください。最後に、何がどこに入ったか短くまとめてください。
何が起きる？ AIがリポジトリを取得し、Desktop Agent をビルドして常駐タスクを登録し、道具一式を配置して、部品ごとに動作確認まで行います。あなたの作業は、見守ることと、AIから質問が来たら答えることだけです。所要時間は数分程度（初回のビルドが大半）です。

方法B：チャットAIに先生役を頼む

ChatGPT、Gemini、Copilot、Claude の通常チャットなど、チャット専用のAIはあなたのPCを直接触れません。でも「先生役」としては優秀です。あなたが手を動かし、AIが次の一手を教えてくれます。

最初にこの文を貼るあなたは私のセットアップの先生です。このガイドを読んでください： https://github.com/thanatos333/agent-hands-kit/blob/main/SETUP.md 私は Windows PC に Agent Hands Kit を「Way C」の手順で入れます。 一歩ずつ案内してください：やることを1つだけ具体的に伝え、私が「できた」と返事するかスクリーンショットを送るまで次に進まないでください。 エラー文を貼ったら、専門用語なしで意味と対処を教えてください。ガイド全文を一度に出さないでください。
  1. AIの指示どおりに1つずつ進める

    クリックや入力はあなたの手で行います。急がず1ステップずつで大丈夫です。

  2. 詰まったらスクリーンショットを送る

    画面の状態を言葉で説明するより、スクショ1枚が一番早いです。「思っていた画面と違う」ときほど送ってください。

  3. 確認のたびに「最後の1行」を貼る

    このキットの道具は、結果を最後の1行で返します。成功は _OK で終わる行、失敗は _FAILED と理由です。その1行をAIに貼れば、成功したかどうかを正確に判断してもらえます。

方法C：自分で入れる（全手順）

使う部品だけ入れればOKです。中心は Desktop Agent で、ほかは任意・独立です。コマンドは PowerShell にそのまま貼れます。

ステップ0：ファイルを手に入れる

  1. ダウンロードする

    GitHub のリポジトリページで Code → Download ZIP を押し、好きな場所（例：C:\agent-hands-kit）に展開します。git がある人は git clone https://github.com/thanatos333/agent-hands-kit.git でもOKです。

ステップ1：Desktop Agent（画面を見る・操作する手足）

  1. .NET 10 SDK を入れる

    Microsoft の公式サイトから無料で入れられます。入れたら PowerShell を開き直して dotnet --version と打ち、バージョンが表示されればOKです。

  2. ビルドして配置する

    展開したフォルダの中で次を実行します。置き場所は %USERPROFILE%\tools\desktop-agent\ で固定です。

    dotnet publish components\desktop-agent -c Release -o $env:USERPROFILE\tools\desktop-agent
  3. ログオン時の自動起動を登録する

    タスク名は AronaDesktopAgent で固定してください（クライアントがこの名前を探します）。

    $exe = "$env:USERPROFILE\tools\desktop-agent\desktop-agent.exe"
$action    = New-ScheduledTaskAction -Execute $exe -Argument "serve"
$trigger   = New-ScheduledTaskTrigger -AtLogOn
$principal = New-ScheduledTaskPrincipal -UserId $env:USERNAME -LogonType Interactive -RunLevel Highest
Register-ScheduledTask -TaskName "AronaDesktopAgent" -Action $action -Trigger $trigger -Principal $principal
Start-ScheduledTask -TaskName "AronaDesktopAgent"

    初回起動時に、アクセス用のトークンが自動生成されます（あなたが触る必要はありません）。タスクトレイにアイコンが出れば常駐中です。

  4. 動作確認（ここだけは省略しないで）

    状態表示と、試しにスクリーンショットを1枚撮ります。

    & $env:USERPROFILE\tools\desktop-agent\desktop-agent.exe status
& $env:USERPROFILE\tools\desktop-agent\desktop-agent.exe screenshot --scale 0.5

    スクリーンショットは %USERPROFILE%\tools\desktop-agent\shots\ に保存されます。開いて、自分の画面が写っていれば成功です。これでAIから desktop.ps1 経由でデスクトップを操作できるようになりました。コマンド一覧はリポジトリの components/desktop-agent/README.md にあります。

ステップ2：PowerShell 道具群

  1. 置き場所を決めてコピーする

    例として C:\agent-home を作り、components\powershell-tools\ と components\app-wrappers\ の中身を C:\agent-home\tools\ にコピーします。

  2. 環境変数 AGENT_HOME を設定する

    道具たちが自分のホームとして参照する変数です。1回だけ設定します。

    [Environment]::SetEnvironmentVariable('AGENT_HOME', 'C:\agent-home', 'User')
  3. 新しい PowerShell で試す

    ウィンドウを開き直して（変数を読み込むため）から実行します。

    powershell -ExecutionPolicy Bypass -File C:\agent-home\tools\tool-help.ps1

    「スクリプトの実行が無効」と言われたら、コマンド例にある -ExecutionPolicy Bypass を付ければその場限りで実行できます。一覧は components/powershell-tools/INDEX.md。なお delegate.ps1 など一部は作者の環境向けの作例なので、使う場合は自分の環境に合わせて調整してください。

ステップ3：アプリ実行ラッパー

  1. 設定は不要。まず画像プレビューで試す

    ラッパーはアプリのインストール場所を自動で探します。まずはアプリ不要の img-peek で感触を掴んでください。

    powershell -ExecutionPolicy Bypass -File C:\agent-home\tools\img-peek.ps1 -Image C:\path\to\any.png
# 最後の行が IMGPEEK_OK ... なら成功
  2. 使いたいアプリで実行する

    例：Blender に自分のスクリプトを実行させる。

    powershell -ExecutionPolicy Bypass -File C:\agent-home\tools\blender-run.ps1 -Script C:\path\to\your_script.py

    成否は終了コードではなく「宣言した成果物ができたか」で判定されます。詳細は components/app-wrappers/INDEX.md。

ステップ4：VOICEVOX ハーネス（任意・音声合成）

  1. VOICEVOX と Python の準備

    VOICEVOX を公式サイトからインストール（既定の場所でOK）。Python 3 も入れておきます。

  2. ハーネスを置いて、仮想環境を作る 
    copy components\voicevox-harness\vv_harness.py C:\agent-home\tools\
copy components\voicevox-harness\vv-say.ps1   C:\agent-home\tools\
cd C:\agent-home\tools
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install numpy soundfile
  3. 試しに喋らせる

    話者 10 は「雨晴はう（ノーマル）」です。エンジンは未起動なら自動で立ち上がります。

    powershell -ExecutionPolicy Bypass -File C:\agent-home\tools\vv-say.ps1 -Text "はじめまして。私の声、聞こえてますか？" -Speaker 10
# 最後の行が VV_OK <wavのパス> なら成功。WAV を再生して聞いてみてください

    合成前にアクセントとピッチの計画が表示され、出力は基本周波数（F0）の実測で検証されます。詳細は components/voicevox-harness/README.md。

通知ウォッチャー（任意） — Windows の通知をAIへの合図に変える補助ツールです。ソースは components/notification-watcher/。初日は飛ばして問題ありません。

AIとのつなぎ方

同じPCのAI

そのまま使えます

Claude Code やローカルLLMなど、同じPCで動くAIは、上記のコマンドをそのまま実行できます。各部品の README と INDEX は「AIに読ませる」前提で書かれているので、場所を教えてあげてください。

クラウドのAI

PCへの道が1本必要

クラウド側のAIからは、SSH（Tailscale等のプライベートネットワーク経由）でPCに入る方法と、共有フォルダを指示と成果物の受け渡し場所にする「ファイル郵便ポスト」を組み合わせます。Desktop Agent 自体は外に公開しません（PCの中だけで待ち受けます）。設計はリポジトリの mailbox/ と patterns/ にあります。

最終チェック：2分ドリル

どの方法で入れた場合も、最後にこれだけ確認してください。

  • Desktop Agent でスクリーンショットを撮り、AIに「画面に何が写っているか」を説明させる
  • そのスクリーンショットを img-peek.ps1 に渡し、最後の行が IMGPEEK_OK になる
  • （VOICEVOXを入れた場合）1文だけ合成して、最後の行が VV_OK になる

全部通れば、あなたのAIに「目と手足」が付いた状態です。導入できると、AIがCADを操作してモデリングするようなことも可能になります（実例ページ）。

困ったときは

症状意味と対処
dotnet が見つからない.NET SDK が未インストールか、インストール前のウィンドウです。SDKを入れて、PowerShellを開き直してください
「スクリプトの実行が無効」と言われる実行例のように -ExecutionPolicy Bypass を付けるか、一度だけ Set-ExecutionPolicy -Scope CurrentUser RemoteSigned を実行してください
トークンが無い／サーバーに繋がらないDesktop Agent 本体が起動していません。Start-ScheduledTask -TaskName "AronaDesktopAgent" で起動してから再試行してください
スクリーンショットが「ロック中」で拒否される仕様です。画面ロック中や Windows の確認ダイアログ（UAC）表示中は操作を受け付けません。ロックを解除して再試行してください
ラッパーが _FAILED で終わる同じ行に理由が書いてあります（対象アプリ未インストール、ファイル不足など）。まずその理由を確認してください
VV_FAILED no python foundvv-say.ps1 と同じフォルダに .venv を作る（ステップ4）か、環境変数 VV_PYTHON で Python を指定してください
VV_FAILED（エンジン関連）VOICEVOX が未インストールか、エンジンが起動できていません。一度 VOICEVOX を手で起動してから再試行してください

安全について

Desktop Agent は 127.0.0.1（自分のPCの中）だけで待ち受け、利用者ごとのトークン認証が必須です。すべての操作はログに残り、トレイアイコンや STOP ファイルでいつでも止められます。「自分のPCを、自分のAIに」使うための道具です。詳しくはリポジトリの SECURITY.md を読んでください。GitHub版の詳細ガイドは SETUP.md にあります。
